# Rubrica formativa de frações — Professor Tutor

Nova versão independente com sete critérios, registro de apoio, NO/EI, bibliografia, modelos PDF/Word e contadores locais de acesso e solicitações de impressão.

Publicar em um novo repositório público chamado tutor-fracoes-rubrica. Em Settings → Pages, selecionar Deploy from a branch, branch main, pasta /(root). A URL só estará disponível após o GitHub confirmar a publicação.

Dados da rubrica e contadores ficam no navegador; não há contagem global ou comprovação de impressão física.
